## 驗收條件

- [ ] **AC1** 假設試點門市有 ≥ 14 天的資料，當店長在 06:00 之後打開 App，則顯示今日推薦 _(BR-001#R8 · e2e)_
- [ ] **AC2** 清單永遠不會超過 5 則推薦 _(BR-001#R4 · 單元 + e2e)_
- [ ] **AC3** 每則推薦都顯示理由，且理由至少包含一個來自該門市自身資料的數字 _(BR-001#R6 · 單元 + 手動)_
- [ ] **AC4** 每則推薦都顯示目前庫存與庫存可售天數，清單標題顯示所使用的資料區間（從 API 讀取，不寫死） _(BR-001#R1、R3 · e2e)_
- [ ] **AC5** 假設門市資料少於 14 天，App 顯示「資料還不夠」，而不是推薦 _(BR-001#R7 · 單元 + e2e)_
- [ ] **AC6** 已停售或供應商無法供貨的商品永遠不會出現 _(BR-001#R5 · 單元)_
