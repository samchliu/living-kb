# 產品背景（Product Context）

**知識狀態：** 權威 · **負責人：** PM · **ID 前綴：** `PROD`

其他所有文件都預設為真的一小組事實：產品為誰而做、解決什麼問題、刻意不做什麼、以及各個詞彙的意思。

讓這個資料夾保持很小。典型內容：

| 文件 | 內容 |
|---|---|
| `PROD-001-vision.md` | 一段願景、目標使用者、核心問題、非目標 |
| `PROD-002-users.md` | 需求會提到的使用者類型／人物誌 |
| `PROD-003-glossary.md` | 領域詞彙（「庫存可售天數」、「SKU」、「店長」）。AI 用它來避免自行發明詞義。 |

沒有專用範本——每個檔案以 [`templates/metadata.yaml`](../../templates/metadata.yaml) 的通用後設資料標頭開頭，然後平實地寫。

**為什麼這對 AI 很重要：** 詞彙表與非目標讓 AI 能察覺某個提議的需求與產品目的相矛盾，或兩份文件對同一個詞有不同用法。
